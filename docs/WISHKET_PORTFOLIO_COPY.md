## 프로젝트 상세

### 1. 포트폴리오 소개

소규모 서비스 사업자가 고객 문의부터 상담, 견적, 진행, 완료까지의 상태를 한 화면에서 관리할 수 있도록 제작한 반응형 운영 대시보드 데모입니다. 실제 고객 데이터나 외부 메시지를 사용하지 않고 가상 데이터만으로 업무 흐름을 검증했습니다.

### 2. 작업 범위

국내외 CRM·업무관리 제품의 공개 자료를 먼저 조사한 뒤, 소규모 외주 운영에 필요한 정보 구조를 설계했습니다. 한국어·영어 전환, 데스크톱·태블릿·모바일 반응형 UI, 목록·보드 보기, 검색·필터, 문의 상세 패널과 단계 변경 흐름을 React와 TypeScript로 구현했습니다.

### 3. 주요 업무

- 문의·상담·견적·진행·완료의 5단계 파이프라인 구성
- 고객명, 상태, 담당자 기반 검색과 필터 제공
- 목록 보기와 칸반 보드 보기 전환
- 문의 상세 패널과 다음 단계 진행 동작 구현
- 데모 문의 생성 및 응답함 상태 표현
- 한국어·영어 UI 전환
- 데스크톱, 태블릿, 모바일 화면 QA
- 단위 테스트, 빌드, 공개 배포 자동화 검증

### 4. 주안점

처음 보는 사용자가 다음 행동을 바로 판단할 수 있도록 상태, 담당자, 최근 활동, 다음 작업을 함께 배치했습니다. 실제 인증, 결제, 메시지 전송 기능이 있는 것처럼 과장하지 않고, 로컬 데모 범위와 가상 데이터 사용을 화면에서 명확히 밝혔습니다. 작은 화면에서도 상세 패널과 조작 버튼이 잘리거나 겹치지 않도록 별도로 검수했습니다.
