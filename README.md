# Forblune ClientFlow

소규모 서비스 팀이 웹사이트·이메일·프리랜서 플랫폼에서 들어온 고객 문의를 놓치지 않고, `신규 → 검증 → 제안 → 협상 → 수주` 단계로 운영하는 **한국어·영어 전환 CRM 대시보드 데모**입니다.

## 검증 가능한 범위

- 대시보드 수치는 화면에 포함된 가상 리드 데이터에서 계산됩니다.
- 검색, 상태·담당자 필터, 목록/보드 전환, 상세 패널, 다음 단계 이동이 동작합니다.
- 모든 연락처와 회사는 데모용 가상 정보이며 실제 고객 데이터가 아닙니다.
- 데이터는 브라우저 메모리에만 존재하고 외부 API로 전송되지 않습니다.
- 인증, 백엔드, 실제 메시지 발송, 결제 기능은 포함하지 않습니다.

## 품질 기준

- 390 / 768 / 1440px 반응형 검수
- 한국어 / 영어 전체 화면 전환
- 명확한 빈 상태, 검색 결과, 위험·기한 상태
- 대시보드 수치와 원본 레코드의 드릴다운 연결
- 키보드 포커스와 44px 이상 주요 터치 영역

## 로컬 실행

```bash
npm install
npm run dev
npm test
npm run build
```

벤치마크와 차별화 기준은 [`docs/benchmark.md`](docs/benchmark.md)에 기록합니다.
